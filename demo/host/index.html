Maintainer's Copilot Demo Host

This page embeds the Maintainer's Copilot widget. The widget runtime loads configuration from the API, then calls /chat with use_llm=false so the demo works in deterministic fallback mode. 

<script
  src="http://localhost:8000/widget.js"
  data-widget-id="demo-widget"
  data-api-base-url="http://localhost:8000"
  data-widget-url="http://localhost:5173">
</script>

data-api-base-url points to the API service. data-widget-url points to the built or Vite-dev widget frontend.
