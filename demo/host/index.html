What it does

Five tools, one conversation

Each message is routed to the right tool automatically. In demo mode a deterministic router handles triage; with Claude enabled, LLM tool-calling takes over.

🏷
Classify Issue
RoBERTa-base fine-tuned on Node.js issues. Returns label + confidence bar across Bug, Question, Enhancement, Docs.
🔍
Extract Entities
Rule-based NER extracts versions, file paths, URLs, CLI flags, function names, and module names from issue text.
📝
Summarize Thread
Extractive summarizer condenses issue title + body into up to 5 bullet points for fast maintainer triage.
📚
RAG Search
Reranked hybrid retrieval (sparse + dense MiniLM + cross-encoder) over 13,580 Node.js doc and resolved-issue chunks.
💾
Write Memory
Explicit-only episodic memory stored in pgvector with 384-dim MiniLM embeddings. Persists across conversations.
